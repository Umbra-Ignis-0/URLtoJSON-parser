# URLtoJSON parser

Консольная утилита на C++ (libcurl) для массового сбора микроразметки **JSON-LD**
(`<script type="application/ld+json">`) со списка страниц.

Писал для QA-задачи: нужно было проверять микроразметку примерно на 1000 страниц сайта
после каждой итерации правок, и таких прогонов набралось больше 15. Вручную это нереально.
Утилита скачивает страницы по списку, сохраняет каждый найденный блок JSON-LD в отдельный
файл и ведёт манифест. По манифесту видно, какие страницы не открылись, какие
отредиректили и где разметки нет.

## Использование

```
URLtoJSON_parserPLUSfilter input.csv [url_col] [category_col] [output_dir]
```

- `input.csv`: CSV в UTF-8 со столбцами «категория» и «URL». Разделитель `,` или `;`
  (как сохраняет русский Excel) определяется автоматически. Строка заголовка допустима, она пропускается.
- `url_col`, `category_col`: номера столбцов, считая с 1. По умолчанию URL во 2-м, категория в 1-м.
- `output_dir`: папка для результатов, по умолчанию `output`.

Пример `input.csv`:

```
category,url
game,https://example.com/games/a
game,https://example.com/games/b
news,https://example.com/news/1
```

Готовый пример для пробного запуска лежит в `examples/links_4game.csv`: 1088 публичных
страниц [4game.ru](https://ru.4game.ru) (главная, игры, магазин, товары, статьи, новости).

```
build\URLtoJSON_parserPLUSfilter.exe examples\links_4game.csv output
```

Прогон по нему занимает несколько минут, потому что страницы скачиваются по одной.

## Результат

- `<категория>_line<номер строки CSV>_<номер блока>.json`: по файлу на каждый блок JSON-LD.
- `manifest.csv`: по строке на каждый блок или каждую страницу без результата.

| Столбец | Значение |
|---|---|
| `category`, `url` | Из входного CSV |
| `http_code` | Итоговый HTTP-код после редиректов (`0`, если страница не скачалась) |
| `final_url` | Итоговый адрес. Отличается от `url`, если был редирект |
| `filename` | Файл с блоком. Пусто, если разметки нет или страница не скачалась |

Манифест перезаписывается при каждом запуске, поэтому повторные прогоны в ту же папку не плодят дубли.
Он сохраняется с тем же разделителем, что и входной CSV, и с BOM, чтобы Excel сразу правильно
показывал кириллицу.

## Сборка (Windows, Visual Studio 2022+)

Зависимости ставятся через [vcpkg](https://vcpkg.io) в manifest-режиме (`vcpkg.json`).

```
set VCPKG_ROOT=<путь к vcpkg>
cmake --preset vcpkg
cmake --build build
```

В Visual Studio vcpkg уже входит в поставку:
`C:\Program Files\Microsoft Visual Studio\<версия>\Community\VC\vcpkg`.
